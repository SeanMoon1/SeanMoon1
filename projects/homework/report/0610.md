### 폰노이만 아키텍처 동작 원리
    폰 노이만 아키텍처(Neumann Architecture)는 컴퓨터의 기본 구조로, 다음과 같은 원리로 동작합니다.

    1.구성 요소

     중앙처리장치(CPU): 연산과 제어를 담당
     메모리: 데이터와 명령어를 저장
     입력장치: 데이터를 입력
     출력장치: 결과를 출력
    
    2.동작 원리

     명령어와 데이터를 모두 메모리에 저장
     CPU가 메모리에서 명령어를 하나씩 읽어와(인출, Fetch) 해석(Decode)하고 실행(Execute)
     프로그램 카운터(PC)가 다음에 실행할 명령어의 주소를 기억
    
    3.특징

     명령어와 데이터가 같은 버스(통로)를 통해 이동(폰 노이만 병목 현상 발생 가능)
     프로그램 내장 방식(Stored Program Concept): 프로그램을 메모리에 저장하고, CPU가 순차적으로 실행
     즉, 폰 노이 만 아키텍처는 "명령어와 데이터를 같은 메모리에 저장하고, CPU가 순차적으로 처리한다"는 것이 핵심입니다.
    

### HTML 시멘틱 태그 역할, DOM 조사

#### HTML 시멘틱 태그 역할

HTML 시멘틱 태그는 웹 문서의 구조와 의미를 명확하게 표현하는 태그입니다. 주요 역할은 다음과 같습니다:

- **의미 전달**: 각 태그가 고유의 의미를 가지므로, 코드만 봐도 구조와 역할을 쉽게 파악할 수 있습니다.
- **접근성 향상**: 스크린 리더 등 보조기기가 문서 구조를 이해하기 쉬워집니다.
- **SEO(검색엔진 최적화)**: 검색 엔진이 페이지의 주요 콘텐츠를 더 잘 파악할 수 있습니다.

##### 주요 시멘틱 태그 예시
- `<header>`: 머리말(로고, 내비게이션 등)
- `<nav>`: 내비게이션 영역
- `<main>`: 문서의 주요 콘텐츠
- `<section>`: 주제별 구역
- `<article>`: 독립적인 콘텐츠(게시글, 뉴스 등)
- `<aside>`: 보조 콘텐츠(광고, 관련 링크 등)
- `<footer>`: 바닥글(저작권, 연락처 등)

---

#### DOM(Document Object Model) 조사

DOM은 HTML, XML 문서를 트리 구조로 표현한 객체 모델입니다.

- **구조**: 문서 전체가 노드(Node)로 구성된 트리 형태
- **역할**: 자바스크립트 등 프로그래밍 언어로 문서 구조, 스타일, 내용 등을 동적으로 조작할 수 있게 함
- **예시**:  
  - 요소 추가/삭제: `document.createElement`, `appendChild`, `removeChild`
  - 속성 변경: `element.setAttribute`, `element.classList.add`
  - 내용 변경: `element.textContent`, `element.innerHTML`

##### DOM 트리 예시
```html
<html>
  <body>
    <header>...</header>
    <main>
      <section>...</section>
    </main>
    <footer>...</footer>
  </body>
</html>
```
위 구조는 DOM 트리로 변환되어 각 태그가 노드로 표현됩니다.
